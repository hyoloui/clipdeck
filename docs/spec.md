# Clipdeck 설계 (가칭)

작성일: 2026-11-21 · 상태: 승인 대기 (설계 검토 반영: MCP 비밀값 숨김 A, 디자인 apple-design)

## 1. 의도와 이유

유료 클립보드 관리자 구독을 대신해 이 맥에서 매일 쓸 클립보드 관리자를 만든다. 사용자는 본인 한 명, 기기는 이 맥 하나다.
추가로 MCP 서버를 내장해 Claude·Codex·Antigravity(agy)가 모두 클립보드 기록을 검색·조회·복사할 수 있게 한다.

성공 기준: 1주일 동안 기존 앱 없이 매일 써도 복사 누락·패널 지연·붙여넣기 실패가 없다. 그 뒤 기존 앱을 삭제한다.

## 2. 기능 범위

| 기능 | 1차 범위 |
|---|---|
| 클립보드 기록(텍스트·이미지·링크·색상·파일), 보관 기간, 일시정지, 전체 삭제 | 포함 |
| 단축키 호출, 현재 앱에 바로 붙여넣기(손쉬운 사용 권한), 일반 텍스트 붙여넣기, 빠른 붙여넣기 | 포함 |
| 검색 + 필터(앱·날짜·타입·Pinboard·기기) | 포함(기기 필터 제외) |
| Pinboard(만들기·이름 변경·삭제·이전/다음 보드 단축키) | 포함 |
| 개인정보: 앱 제외, 민감 내용 제외, 임시 내용 제외, 화면 공유 중 숨김 | 포함 |
| 메뉴바 아이콘, 로그인 시 실행, 효과음 | 포함 |
| MCP 서버(LLM 클라이언트가 클립보드 기록을 검색·조회·복사) | 포함(§6) |
| 스택 붙여넣기, 항목 편집(서식·이미지 회전·배경 제거) | 제외(2차 후보) |
| iCloud 동기화·공유 Pinboard, 화면 내용 기반 추천, Siri·단축어, 위젯, iOS 키보드 | 제외 |

## 3. 목표 · 비목표 · 반목표

목표
- 복사한 내용을 빠짐없이 저장하고, 단축키 한 번 → 키보드만으로 골라 현재 앱에 붙여넣는다.
- 세 LLM 클라이언트가 같은 MCP 서버로 기록을 쓴다. 등록은 `skillshare mcp` 한 곳에서 관리한다.

비목표
- 동기화·공유, iOS, App Store 배포, 기존 앱의 데이터 가져오기, AI 추천.

반목표(동작해도 실패로 본다)
- 복사가 가끔 빠진다.
- 패널이 늦게 뜬다(목표: 단축키 → 표시 100ms 이내).
- 붙여넣은 뒤 원래 앱으로 포커스가 돌아가지 않는다.
- 비밀번호처럼 민감하다고 표시된 내용이 DB에 남는다.
- MCP로 기록을 삭제할 수 있거나, 비밀값으로 표시된 항목이 MCP 응답에 나온다.
- 다른 클립보드 앱의 이름·아이콘·화면 모양을 따라 한다.

## 4. 제약

- macOS 26.6.2, Swift 6.4, **Xcode 없음(Command Line Tools만)**. SwiftPM으로 빌드하고 `.app` 번들은 스크립트로 조립한다.
- 테스트는 Swift Testing(`import Testing`)만 쓴다. CLT에는 XCTest가 없고 `Testing.framework`는 있다.
- 코드 서명 인증서가 0개다. 재빌드마다 서명이 바뀌면 손쉬운 사용 권한(TCC)이 풀리므로 로컬 자체 서명 인증서 `Clipdeck Local Signing`을 로그인 키체인에 만들어 계속 쓴다. 인증서 생성 시 키체인 승인 창이 뜰 수 있다(사용자 조작 필요).
- 외부 의존성은 최소. 시스템 SQLite3(C API, FTS5)를 쓰고 DB 라이브러리는 넣지 않는다.

## 5. 접근 방식 (검토한 3가지)

1. **네이티브 Swift 앱 + stdio MCP 바이너리** — 채택. 상주 메모리가 작고, 단축키·바로 붙여넣기가 가장 안정적이다. MCP가 DB를 직접 읽으므로 앱이 꺼져 있어도 조회된다.
2. 앱이 HTTP MCP 서버를 띄우는 방식 — 앱 실행 의존, 포트·토큰 관리, 클라이언트별 인증이 붙어 1인 로컬 도구에 과하다.
3. Electron/Tauri — 상주 메모리가 크고 바로 붙여넣기는 결국 네이티브 코드가 필요하다.

디자인: **apple-design 원칙 + macOS 시스템 요소**(사용자 선택). 검토한 다른 안:
- Astryx 토큰을 SwiftUI로 옮기기 — 맥 기본 앱과 결이 달라지고 토큰 파일을 따로 관리해야 해서 제외.
- WebView로 Astryx 컴포넌트 사용 — 패널 표시 지연, 메모리 증가, 키보드 브리지 비용 때문에 제외.

## 6. 설계

### 6.1 구성

```
~/Desktop/project/clipdeck/       SwiftPM 패키지, git 저장소
  Sources/ClipdeckCore/           모델, SQLite 저장소, 캡처 필터, 검색, 보관 정책
  Sources/Clipdeck/               앱(AppKit + SwiftUI): 메뉴바, 패널, 설정, 캡처, 붙여넣기
  Sources/ClipdeckMCPKit/         MCP 도구, JSON-RPC 처리
  Sources/clipdeck-mcp/           stdio MCP 서버 실행 파일
  Tests/ClipdeckCoreTests/        Swift Testing
  Resources/                      Info.plist, 아이콘, 효과음
  scripts/bundle.sh               빌드 → .app 조립 → 서명 → ~/Applications 설치
  scripts/make-signing-cert.sh    자체 서명 인증서 1회 생성
```

설치 결과: `~/Applications/Clipdeck.app`, MCP 실행 파일은 `~/Applications/Clipdeck.app/Contents/MacOS/clipdeck-mcp`.
Info.plist: `LSUIElement = true`(Dock 아이콘 없음), 번들 ID `local.hyoloui.clipdeck`, 최소 macOS 14.

### 6.2 저장

- DB: `~/Library/Application Support/Clipdeck/clipdeck.sqlite`, WAL 모드, `busy_timeout` 설정(앱과 MCP가 동시 접근).
- 큰 데이터(이미지·RTF·HTML)는 `.../Clipdeck/blobs/<sha256>` 파일로, DB에는 경로와 해시만.
- 테이블(개요): `items`(id, kind[text|link|image|file|color], 미리보기 텍스트, content_hash, source_app_bundle_id, source_app_name, mcp_hidden, created_at, last_used_at, use_count), `item_representations`(item_id, UTI, 데이터 또는 blob 경로), `pinboards`(id, name, color, sort), `pinboard_items`(다대다), `items_fts`(FTS5, 텍스트 검색용).
- 같은 content_hash가 다시 복사되면 새로 만들지 않고 `last_used_at`만 올린다.

### 6.3 캡처

- `NSPasteboard.general.changeCount`를 0.5초 간격으로 확인한다(macOS에 변경 알림 API가 없음).
- 원본 표현을 UTI별로 저장해, 붙여넣을 때 서식을 그대로 복원한다. 종류 판정 순서: 파일 URL → 이미지 → 색상 → 링크(텍스트 전체가 URL) → 텍스트.
- 저장하지 않는 경우:
  - `org.nspasteboard.ConcealedType`(민감), `TransientType`·`AutoGeneratedType`(임시) 표시가 있음 — 설정으로 켜고 끔, 기본 켬
  - 복사 당시 앞에 있던 앱이 제외 목록에 있음(기본: 키체인 접근, 1Password, Bitwarden 등 설치된 비밀번호 관리자)
  - 일시정지 중(무기한 또는 15분·1시간·8시간)
  - Clipdeck이 붙여넣기 위해 직접 쓴 내용(자체 표시 UTI로 구분, 대신 해당 항목의 `last_used_at` 갱신)
- **비밀값 표시(MCP 숨김, 사용자 선택 A):** 저장할 때 텍스트를 비밀값 패턴과 대조해 걸리면 `mcp_hidden = 1`로 저장한다. 로컬 패널에서는 그대로 보이고 붙여넣을 수 있다(목록에서는 앞 4자 외 가림 처리 + 자물쇠 표시, 미리보기에서 펼쳐 보기).
  - 패턴(시작 목록, 빌더가 테스트와 함께 보강): `sk-`·`sk-ant-`·`sk-proj-`, `ghp_`·`gho_`·`github_pat_`, `xox[abpr]-`, `AKIA[0-9A-Z]{16}`, `AIza[0-9A-Za-z_-]{35}`, JWT(`eyJ….….…`), `-----BEGIN … PRIVATE KEY-----`, `password=`/`token=`/`secret=` 형태의 키-값, 공백 없는 20자 이상 문자열 중 엔트로피가 높은 것(기준값은 빌더가 오탐 테스트로 정함).
  - 설정의 "MCP에서 숨길 앱" 목록에 있는 앱에서 복사한 항목도 `mcp_hidden = 1`.
  - 패널에서 항목별로 MCP 숨김을 켜고 끌 수 있다(오탐·미탐 수정용).
  - 한계(문서화): 셸을 쓰는 에이전트는 DB 파일을 직접 열 수 있으므로 이 표시는 MCP 경로만 막는다. 암호화는 하지 않는다(사용자 선택).
- 보관 기간: 1일·1주·1개월·1년·무제한(기본 1개월). Pinboard에 들어간 항목은 지우지 않는다. 앱 실행 시와 하루 1번 정리.

### 6.4 패널 (화면 모양)

화면 하단의 가로 띠가 아니라 화면 중앙에 뜨는 목록 + 미리보기 패널이다(제 판단: 키보드 탐색에 유리하고 다른 클립보드 앱과 구분됨).

```
┌──────────────────────────────────────────────────────────┐
│ 🔍 검색…                          [전체▾] [타입▾] [앱▾]   │
│ 기록 · 업무 · 코드조각 · +            (Tab으로 보드 전환)   │
├────────────────────────────┬─────────────────────────────┤
│ ▸ 1  npm run dev     Ghostty 2분│                         │
│   2  https://…        Arc   5분│   선택 항목 미리보기      │
│   3  [이미지] 1280×720  Figma 1시간│  (텍스트·이미지·링크·파일)│
│   4  #4F7CFF          Figma 어제│   출처 앱 · 시각 · 크기   │
│   …                            │                          │
├────────────────────────────┴─────────────────────────────┤
│ ↩ 붙여넣기  ⇧↩ 일반 텍스트  ⌘1-9 바로  ⌘P 고정  ⌫ 삭제  esc │
└──────────────────────────────────────────────────────────┘
```

- `NSPanel`(nonactivating, floating, 모든 Space에 표시). 화면 공유 중 숨김 옵션은 `sharingType = .none`.
- 기본 단축키 `⇧⌘V`(설정에서 변경). 전역 단축키는 Carbon `RegisterEventHotKey`로 의존성 없이 구현.
- 열 때 검색창에 포커스, 타이핑 즉시 FTS 검색. 목록은 최근 사용 순.
- 키: ↑↓ 이동, ↩ 붙여넣기, ⇧↩ 일반 텍스트, ⌘1–9 해당 순번 즉시 붙여넣기, ⌘P Pinboard에 추가(보드 선택 메뉴), ⌫ 삭제, Tab/⇧Tab 보드 전환, ⌘C 복사만, Esc 닫기. 마우스 더블클릭도 붙여넣기.
- 다크/라이트 모드 모두 지원, 동작 줄이기(Reduce Motion) 설정 시 애니메이션 생략.

### 6.5 붙여넣기

1. 패널을 열기 직전의 앞 앱(`NSWorkspace.frontmostApplication`)을 기억한다.
2. 선택 항목을 클립보드에 쓴다(일반 텍스트 모드면 `public.utf8-plain-text`만).
3. 패널을 닫고 기억한 앱을 활성화한 뒤 `CGEvent`로 ⌘V를 보낸다.
4. 손쉬운 사용 권한이 없으면 3을 건너뛰고 "클립보드에 복사됨" 알림 + 권한 안내를 보여준다. 설정에서 "현재 앱에 붙여넣기 / 클립보드에만 복사" 선택, "항상 일반 텍스트" 옵션.

### 6.6 메뉴바와 설정

- 메뉴바: 열기, 일시정지(시간 선택)/재개, 설정, 기록 전체 삭제(확인 창), 종료.
- 설정 창(SwiftUI) 탭: 일반(로그인 시 실행 `SMAppService`, 효과음, 메뉴바 아이콘), 단축키(전역은 "패널 열기" 하나뿐. "일반 텍스트로 붙여넣기"·"이전/다음 보드"는 패널 안에서만 동작하는 키이며 여기서 다른 키로 바꿀 수 있다 — 제 판단), 붙여넣기 방식, 기록(보관 기간, 줄이면 확인 창), 개인정보(제외 앱 추가·삭제, 민감·임시 내용 제외, 화면 공유 중 숨김), Pinboard 관리, MCP(실행 파일 경로, 등록 명령 복사, 상태, MCP에서 숨길 앱 목록, 비밀값 자동 숨김 켜기/끄기 — 기본 켬).

### 6.7 MCP

- 실행 파일 `clipdeck-mcp`, stdio 전송, MCP 프로토콜. 공식 `modelcontextprotocol/swift-sdk`가 Swift 6.4·CLT에서 빌드되면 사용하고, 안 되면 JSON-RPC 2.0을 직접 구현한다(빌더 판단).
- **`mcp_hidden = 1` 항목은 모든 도구에서 제외한다**(검색 결과·목록·Pinboard 목록·`get_item`·`copy_to_clipboard`의 id 조회 모두. 숨김 항목 id로 요청하면 "없음"과 같은 응답). 조회는 저장소 계층의 MCP 전용 쿼리 한 곳에서만 하게 해서 빠뜨릴 수 없게 한다. `create_text_item`으로 들어온 텍스트도 같은 패턴 검사를 거친다.
- 호출당 상한은 그대로(목록 최대 100개, 텍스트 최대 100KB). 호출 횟수·시간당 상한은 두지 않는다(제 판단: 숨김 처리가 실제 방어선이고, 셸 접근 때문에 횟수 제한은 효과가 없다).
- DB를 직접 연다. 쓰기 뒤에는 Darwin 알림(`local.hyoloui.clipdeck.db-changed`)을 보내 앱 목록을 새로 고친다.
- 도구(삭제 도구는 두지 않는다):

| 도구 | 입력 | 결과 |
|---|---|---|
| `search_items` | query, kind?, app?, pinboard?, since?, limit(기본 20, 최대 100) | id·종류·미리보기(200자)·출처 앱·시각 |
| `list_recent` | limit(기본 20, 최대 100), kind? | 같음 |
| `get_item` | id | 텍스트 전문(최대 100KB, 넘으면 잘림 표시), 이미지는 MCP image 콘텐츠(긴 변 1024px로 축소), 파일은 경로 목록 |
| `list_pinboards` | — | id·이름·항목 수 |
| `list_pinboard_items` | pinboard, limit | 항목 목록 |
| `copy_to_clipboard` | id 또는 text | 클립보드에 씀 → 사용자가 ⌘V |
| `create_text_item` | text, pinboard? | 새 항목 id |
| `add_to_pinboard` | id, pinboard | 결과 |

### 6.8 LLM 등록 (중앙 관리)

1. MCP 서버: `skillshare mcp add clipdeck --target claude --target codex --target antigravity -- ~/Applications/Clipdeck.app/Contents/MacOS/clipdeck-mcp` (실제로는 절대 경로). `skillshare mcp check clipdeck --live`로 세 클라이언트 동기화와 실제 호출을 확인한다.
2. 사용법 스킬: `skillshare-managed new clipdeck -P none`으로 중앙 스킬 `clipdeck`을 만들고, 도구 목록·언제 쓰는지("아까 복사한 거", "클립보드에서 찾아줘")·주의사항(민감 내용을 대화에 옮기지 말 것)을 적는다. `skillshare-managed sync` 후 각 앱 경로에 파일이 생겼는지 확인한다(차단돼도 exit 0이므로).

### 6.9 디자인 (apple-design + macOS 시스템 요소)

구현 전에 `apple-design` 스킬을 읽고 아래처럼 SwiftUI/AppKit에 대응시킨다.
- 색: 시스템 의미 색만(`Color.primary/secondary`, `.accentColor`, `NSColor.labelColor`, `separatorColor`, `selectedContentBackgroundColor` 등). 직접 정한 hex 색 금지. 다크 모드·대비 높이기·강조 색 설정이 자동으로 따라온다.
- 재질: 패널 배경은 `NSVisualEffectView`(`.hudWindow` 또는 `.popover` 재질, `.behindWindow`). 투명도 줄이기 설정 시 시스템이 불투명으로 바꾼다.
- 글꼴: SF Pro 시스템 글꼴과 텍스트 스타일(`.body`, `.callout`, `.caption`), 코드성 텍스트는 `.monospaced()`.
- 반응: 키 입력·선택 표시는 즉시(애니메이션 없이). 인위적 지연·디바운스 금지(FTS 검색도 입력마다 즉시).
- 움직임: 패널 등장/퇴장·선택 이동은 SwiftUI 스프링(`.spring(response: ~0.3, dampingFraction: ~0.85)` 수준), 도중에 끊고 되돌릴 수 있게. `accessibilityReduceMotion`이면 페이드만.
- 절제: 장식 없이 내용 우선. 간격은 4pt 배수의 상수 몇 개(`Layout.swift`)로만 관리.
